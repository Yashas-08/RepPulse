# 📖 Overview

RepPulse is a production-ready fitness tracking application designed to help users build consistency in their fitness journey.

Whether you're tracking your first workout or chasing new personal records, RepPulse provides a clean, intuitive, and responsive experience across desktop and mobile devices.

The application also works offline through Progressive Web App (PWA) support.

# 🚀 Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/Yashas-08/RepPulse.git

cd RepPulse
```

## 2. Install dependencies

```bash
npm install
```

## 3. Create your environment file

Create a `.env` file in the project root.

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

---

## 4. Run locally

```bash
npm run dev
```

---

## Production Build

```bash
npm run build
```
